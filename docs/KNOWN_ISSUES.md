# 已知问题与兼容范围

V1.1.4 是预览版。

- 核心使用窗口像素合成，没有网页 DOM 语义。灰阶图片、非标准配色、特殊面板可能局部受到背景识别影响。当前保留原有前景覆盖率；已撤回导致字体变粗、发亮和壁纸过暗的强制对比处理。可按实际素材调遮罩与面板强度，或暂停/恢复原样。
- 客户端日夜切换依赖官方设置界面的可访问控件。最后一版完整按钮流程未完成实机验收；客户端升级后控件可能变化。遇到失败会提示原因，不修改官方安装文件。
- 静态场景提取只读取可定位的原图/视频，不复刻完整粒子、木偶、光效、3D 或脚本。网页提取不运行网页脚本。无法定位高清主图时不会以封面代替。
- 场景录制依赖用户已安装的 Wallpaper Engine，仅生成阶段调用。录制片段静音，不保留交互，循环不保证无缝，复杂场景性能因设备而异。
- 实机主要覆盖 Windows 11 x64 的部分官方 ChatGPT/Codex 客户端版本。Windows 10 1903+、HDR、跨显示器 DPI、所有缩放组合及冷启动时机未作完整覆盖；不支持 macOS/Linux。
- 一些只捕获原应用表面的截图或录屏工具看不到外部合成层。后台 prepared 仅表示画面已准备或被其他窗口遮挡，不等同已在前台看到效果。
- 管理器需运行才能观察客户端启动和显示背景。关闭管理器会结束所属后台；托盘运行才会持续保持。

报告问题时请提供最小复现步骤；截图和日志请先移除聊天内容、个人目录及账号信息。无需公开完整的第三方壁纸项目。
