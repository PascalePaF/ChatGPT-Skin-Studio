ChatGPT Skin Studio V1.1.4

【安装与开始】
运行 Windows x64 安装包。软件自带 .NET 运行时，不需要 Node.js、开发工具或 API Key。
从原来的官方入口打开 ChatGPT 桌面端，再打开 Skin Studio。无需关闭当前任务、修改官方安装包、开启调试端口或改用专用入口。

【界面与图标】
左侧为壁纸库、启动动画、设置与连接；右侧为对应工作区。左下可直接点“日间 / 夜间”，也可从“管理器外观”选择万圣夜；立即切换并记住选择。管理器外观与客户端明暗设置独立。
“收起预览”隐藏预览，让完整工作区展示壁纸卡片；“展开预览”显示左侧壁纸列表、右侧大预览。双击壁纸卡片也可展开，状态会保存，预览区本身无需上下滚动。
生成离线视频、时长、清晰度、取消、进度和保存操作固定在图库下方，不会随预览收起。选择场景或网页可生成，选择已有视频时可直接预览/应用；不适用的生成按钮会保留并提示原因。
点击固定工具栏“离线视频”可直接查看本地视频，自动清除当前搜索和分组限制。生成的视频标示为“离线视频”，没有封面时使用播放图标。
点击图库右上“全部壁纸”会清除搜索、来源与分组筛选，恢复完整壁纸库。生成完成会保留完整图库并选中新副本，不会切到仅本地素材。
窗口、Windows任务栏和右下通知区使用统一的薄荷色窗口图片图标；通知区图标可能在Windows隐藏图标列表中。双击托盘图标打开管理器，右键可恢复原样或退出。
左侧“万圣夜已上新”可预览“万圣夜庄园”：庄园、石阶、南瓜灯和月光山谷插画，加上轻微烛光、夜雾与微光变化。点击“应用全局皮肤”后才用于客户端，不会仅因浏览而应用。原图实际尺寸1672×941，会如实显示；构图遵循当前适配模式，没有自动运镜或局部推近。

【设置全局皮肤】
在“壁纸库”选择素材，查看大预览，再点“应用全局皮肤”。应用期间壁纸浏览、搜索、预览继续可用。
“原始壁纸预览”显示真实素材；“当前客户端效果”使用当前可见客户端的实时画面，可能包含当前聊天内容，仅在本机处理，不上传。
默认“完整等比 · 深色毛玻璃”：前景完整显示原画面，空余区域使用黑色底毛玻璃。“完整等比 · 浅色毛玻璃”使用白色底，适合浅色界面。两种模式都保留清晰主体，不裁切、不变形；补边由当前壁纸去色模糊、黑/白底色和细微颗粒生成，没有彩色泛光，也不读取其他应用或桌面制造补边。
“完整等比 · 纯色留边”保留深色纯底，不裁切、不变形。
“等比铺满 · 会裁切”保持物体比例并填满窗口，会裁掉部分边缘；需要完整画面时使用前三种模式。
“拉伸铺满 · 会变形”保留整幅画面，但会改变物体比例。后两种模式只在主动选择后使用。
V1.1.0/V1.1.1的extend补边设置升级为深色毛玻璃，主动选择的纯色留边和拉伸设置保留。素材文件内自带的黑边不会被裁除。
设置与连接 → 毛玻璃补边：底色浓度越高越接近纯黑/纯白，纹理越淡；模糊程度只改变补边，不改变中央清晰度。两种毛玻璃共用这些参数，在其他显示模式下会保留参数并停用控件。极光、暮紫、深海按窗口生成；万圣夜庄园使用插画原图，遵循图片适配模式。
背景按客户端浅色/深色使用对应遮罩与面板底色，保留原有字体边缘；已撤回强制文字加重与全图压暗/泛白。原始壁纸预览保持原画。遮罩与面板底色强度可调，调整后点击应用才用于客户端。
客户端最小化时点击应用，软件会恢复已验证的官方窗口后继续；不需要关闭或重启客户端。
设置与连接 → ChatGPT客户端外观：选择日间浅色或夜间深色，点“切换客户端主题”。管理器暂时停用合成层，通过官方设置页操作主题控件，确认后恢复原来的皮肤；无需重启或改安装文件。切换过程中请保持官方窗口可见，避免同时操作设置；控件无法验证时会停止并给出原因。
暂停可继续上次皮肤；“恢复原样”停止皮肤并取消自动恢复。客户端保持运行。
窗口最大化、还原或拖动改变大小时，暂时显示真实原界面，尺寸匹配后恢复皮肤；原界面仍可点击。若恢复失败只退出皮肤，不关闭客户端。左下导航轨头像独立保留原像素。

【Wallpaper 离线抓取】
自动识别本机Steam库、Workshop 431960、Wallpaper本地项目及手动目录；无需启动Steam或Wallpaper Engine。
图片与MP4直接读取原文件。场景包沿主图引用读取TEX最高分辨率纹理，解压为原尺寸图片并缓存到本机。静态主图不含场景粒子、光效、木偶动画、脚本或作者的完整图层合成；纯3D、程序生成或只有小纹理的场景可能没有可提取高清主图，会明确提示，不拿封面或模型贴图冒充壁纸。
网页项目只提取现有原图或受支持视频，不运行网页脚本；多图片网页目前选择较大的原素材，不保证与网页当前选项构图相同。
选择壁纸后自动离线提取、预览，点击“应用全局皮肤”直接使用。没有引擎运行要求，也不会切换Windows桌面壁纸。
“保存到本地库”会保留独立的原图或视频副本；之后原项目被移动、退订或删除，这份副本仍可用。“本地库”筛选同时显示导入和抓取素材，可移除自己的副本，原项目保持不变。
提取缓存位于本机数据目录extracted；复制到本地库的副本位于media。原项目变更后重新读取；普通运行不上传原图或聊天内容。

【壁纸分组、删除与自动添加】
库上方可按来源和分组筛选；新建分组后，选中壁纸，在底部选择目标并点“移动到分组”。Ctrl/Shift可多选。分组可重命名，删除分组只把成员移到“未分组”，不删除壁纸。
“移出壁纸库”对所有来源生效。默认保留原文件与本地副本，可在设置中“恢复已移出的壁纸”；移出后不会因自动扫描而重新出现。
移出对话框可勾选“同时删除管理器保存的本地副本”，此项不可恢复；Wallpaper Engine与手动目录中的外部原文件始终保留。正在使用的皮肤须先恢复原样再移出。
设置里默认开启每30秒后台自动扫描，支持Steam/Wallpaper项目与手动目录内的普通图片、视频。新下载或复制到已添加目录的壁纸会自动加入；也可点“立即扫描”。扫描保留当前浏览选择和已应用皮肤，不会因为发现新壁纸自动换肤。

【场景一次生成，之后离线播放】
需要场景的光效、粒子等动态效果时，选择场景或网页项目，点击预览下方“生成离线视频”。可选10、20、30秒，桌面比例高清（最长边不超过3840）、2560×1440、3840×2160。没有可提取静态主图的项目也可以尝试生成。
仅此操作需要Wallpaper Engine：软件会临时打开引擎，在桌面之外的唯一独立窗口渲染并生成静音MP4，不改变桌面壁纸选择。原本未运行的引擎由本次任务启动，结束后随任务回收；原本已运行的引擎保留。
完成后完整图库会选中“壁纸名称 · 动态副本”；也可点击“离线视频”集中查看本地视频。之后预览或应用不需要Wallpaper Engine。生成期间可以继续浏览其他壁纸，点击“取消生成”放弃本次任务；已应用皮肤和已有副本保留。
这是实际渲染画面的H.264片段，不是引擎原生导出。片段循环不保证首尾无缝，不含声音、鼠标交互或持续脚本逻辑；复杂场景的生成速度取决于本机性能。生成失败时静态原图仍可使用。

【本地导入】
图片：PNG、JPG、JPEG、BMP、GIF（首帧）。视频：MP4、M4V、WMV。标准 H.264 MP4 兼容性最好，其他编码取决于系统解码器。
导入复制原文件，不压缩、转换。移除只删除管理器副本，保留最初的文件。
Wallpaper 项目直接引用原资源；移动或退订后须重新识别或导入。

【启动动画与后台】
启动动画可启用、预览，选择内置过渡或本地 MP4，调整时长。管理器运行时官方窗口新出现才播放；正常换肤不会重复播放。
管理器不运行时不能观察启动。右上角“后台运行”留在托盘，也可自愿开启 Windows 登录启动。
右上角关闭会真正退出，同时回收所属背景和读取任务；托盘也可退出。
客户端最小化时隐藏背景、暂停本地视频；窗口关闭后释放后台。重新打开可按设置恢复上次皮肤。

【显示边界】
这是本机窗口合成，不向官方客户端插入网页或修改 app.asar。建议官方深色界面。像素识别没有网页语义，灰阶图片、特殊面板、自定义主题可能局部变色，不合适时可恢复原样。
系统屏幕截图可包含合成结果，部分只捕获原应用表面的工具不包含外部合成层。
客户端被遮挡时显示“画面已准备”，不会把该状态冒充已在前台呈现。
当前实机对象是 Windows 11 x64 合并版 ChatGPT/Codex。Windows 10 1903+、其他客户端版本和 HDR 仍可能有兼容差异。
视频静音。场景原图是静态图片，不含 Wallpaper Engine 的声音、交互或实时动画；不改变桌面声音设置。

【数据与卸载】
本地数据：%LOCALAPPDATA%\ChatGptSkinStudio
普通运行不保存聊天截图；开发诊断的显式截图操作例外。无云端上传。
从 Windows“已安装的应用”卸载。卸载回收管理器登录启动项，保留本地素材和设置便于重装；原壁纸、Wallpaper Engine 和官方客户端保留。
