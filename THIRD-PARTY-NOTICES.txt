ChatGPT Skin Studio 1.1.4

The manager, renderer, procedural backgrounds and icon were independently
implemented. No reference project's source code, application binary,
wallpaper collection or logo is included in this release.

The bundled Lantern Manor illustration was generated and refined for this
project using the built-in image_gen tool. Generation prompts and actual
source dimensions are preserved in the source project's assets directory.
It is not extracted from a user's Wallpaper Engine library.

and third-party notice files are included under licenses/dotnet and

Wallpaper Engine is a separately installed product and is not included.

terms. They are not bundled. ChatGPT and Codex are OpenAI products; this
companion is independent, not an official OpenAI extension.
